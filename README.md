## ⚡ Visão Geral (The Philosophy)

Este repositório contém meu portfolio interativo pessoal, desenvolvido com uma abordagem **direta, incomum e sem ruídos corporativos**:

- 🖥️ **MF-CLI Console:** Terminal UNIX interativo embutido direto no navegador com histórico de comandos, easter eggs e execução em tempo real.
- 🔊 **Web Audio Synthesis:** Feedback sonoro tátil gerado nativamente via osciladores do Web Audio API (zero arquivos de áudio pesados).
- 🌌 **Neural Mesh & Matrix Rain:** Canvas interativo que responde à aceleração do cursor do mouse e permite alternar para chuva digital em tempo real.
- ⚡ **Benchmarking Toy:** Teste de estresse computacional executado na thread do browser do visitante para aferir throughput de CPU e latência de rendering.
- 🌐 **Bilingue (PT-BR / EN):** Alternância instantânea de idioma com 1 clique.
- ⌨️ **Command Palette (⌘K / Ctrl+K):** Acesso rápido a qualquer seção ou canal de contato pelo teclado.

## 📜 Manifesto de Engenharia

1. **Código limpo não é vaidade, é velocidade:** Engenharia de verdade não cria labirintos desnecessários. Código bom é legível e direto.
2. **Se precisa de tutorial, a interface falhou:** Interfaces devem ser intuitivas e responder instantaneamente à intenção do usuário.
3. **Performance é uma feature:** Cada 100ms de atraso custa retenção. Tolerância zero para bloatware e scripts desnecessários.
4. **Menos reuniões, mais commits que funcionam:** O melhor feedback é um produto funcional rodando na mão do usuário real.

- Mantém o conteúdo, nome e contatos originais a pedido de fidelidade visual.
- HTML, CSS, módulos Framer, imagens e fontes estão em dist/.

- O case protegido permanece protegido. Não inclui acesso ao projeto editável no Framer nem ao backend privado.
